## 使うときの約束（Claude Code 向け）

- **優先順位**: note studio のルールが書籍のテクニックより優先。セールス系の技法（希少性・警告・煽り）を使う場合も、
  誇大表現（「絶対」「誰でも稼げる」など）・根拠のない数字・不安の過度な煽りにはしない。
- **周辺領域の2冊** は企業向けが前提。個人・フォロワーゼロの状況に合う部分だけを使う。
- **出典の書き方**: `{"type": "book", "title": 書名, "publisher": "著者／出版社", "location": "第3章 ○○ など"}`。
  location には本に印刷されたページ番号か章・見出し名を書く（PDFのページ番号はずれるので使わない）。
- **読み方**: PDFはOCR済みで文字を抽出できる。`tools/pdftool` で読む（使い方は CLAUDE.md）。
  『伝え方が9割』は縦書きのため1文字ずつ改行されて抽出されるので、つなげて読む。一部に文字化けがあるので、引用する前に画像で確認する。

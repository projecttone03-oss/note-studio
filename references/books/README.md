# 参考書籍フォルダ

記事の企画・執筆で参考にしてほしい書籍を置く場所です。
置いたら `_書籍リスト.md` に1行追加してください（どのテーマで・何のために使うかを書くと、Claude Code が使い分けられます）。

## 置き方

```
references/books/
├── _書籍リスト.md          ← 書籍の一覧（ここに追記）
├── 書名A/
│   ├── 書名A.pdf           ← 本体（DRMのないPDF・EPUBなど）
│   └── メモ.md             ← 読書メモ・特に参考にしてほしい章（任意）
└── 書名B/
    └── メモ.md             ← 本体を置けない場合はメモだけでもOK
```

1冊ごとにフォルダを分けるのがおすすめですが、ファイルを直接置いても構いません。

## 対応している形式

| 形式 | 読めるか | 備考 |
|---|---|---|
| PDF | ◎ | そのまま読めます（スキャンPDFも可） |
| テキスト・Markdown（.txt / .md） | ◎ | 読書メモ・ハイライトの書き出しに最適 |
| EPUB（DRMなし） | ○ | 中身のテキストを取り出して読みます |
| 画像（.jpg / .png） | ○ | 必要なページの写真。枚数が多いと時間がかかります |
| Kindle などDRM付きの電子書籍 | × | ファイルとしては読めません（下記参照） |

## 注意（著作権）

- **DRM（コピー防止）を外して置かないでください。** 私的使用の目的でも、技術的保護手段を回避してコピーすることは
  著作権法で認められていません（第30条第1項第2号）。Kindle本などは、本体の代わりに
  **読書メモ・ハイライト・参考にしたいページ番号** を `メモ.md` に書いてください。
- このフォルダの中身は **あなた個人の参照用** です。他人に共有したり、ネットにアップロードしたりしないでください。
- 記事での使い方のルール（Claude Code もこれに従います）:
  - 書籍の内容を要約・言い換えしただけの記事にはしない（書籍の要約記事は販売しない）
  - 書籍は「視点・構成の参考」「事実の裏取りのきっかけ」として使い、事実は公的情報・一次情報で確認する
  - 引用する場合は必要最小限にとどめ、自分の文章が主、引用が従の関係を守り、
    「」や引用ブロックで区別し、書名・著者・出版社・該当ページを明記する（著作権法第32条）
